## HARDEN-D05: Range Jacobian: STM vs re-propagation discrepancy 1e-6..1e-4

- **Location:** lunar_od/dynamics.py dynamics_jacobian_a_matrix (variational equations)
- **Discovered:** Phase 17-R1O-D2 / HARDEN
- **Root cause:** the variational A matrix omits the SRP position gradient K*dg/dr (documented Phase 13/16 approximation, mean 4.02e-13 of the gravity gradient); the gradient is concentrated in penumbra (max 1.09e-11 s^-2, median 7.7e-19) and its effect accumulates secularly
- **Physical / numerical / scientific effect:** range-Jacobian state columns relative error 2e-6..1e-5 over 4 orbits at rtol 1e-13; the event (light-time) derivative itself is exact (LIN error 1e-8..9e-8, falling with h)
- **Status:** ROOT_CAUSE_KNOWN_DOCUMENTED_APPROXIMATION
- **Class:** RECOMMENDED_FOLLOWUP
- **Repair:** none in HARDEN (dynamics.py is R2-protected; adding the gradient is a model change); first-order prediction from the omitted gradient reproduces the observed error (corr >= 0.999 on 4/6 columns); NO_SHADOW and K=0 controls agree to the integrator floor
- **Regression:** tests/test_harden_boundaries.py::test_omitted_srp_position_gradient_is_the_range_jacobian_root_cause, ::test_range_jacobian_root_cause_evidence_is_consistent
- **Historical reproduction path:** examples/phase17_harden_range_jacobian.py [--predict]
